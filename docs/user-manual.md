## 1. ミーティングを始める / 参加する

アプリを開くとトップページが表示されます。

![ホーム画面](screenshots/01_home.png)

### 新しいミーティングを作成する

**「New Meeting」** ボタンをクリックすると、ランダムなルームIDが生成されてロビーに移動します。

### 既存のミーティングに参加する

ルームIDまたはリンクを **「Enter code or link」** の入力欄に貼り付けて **「Join」** をクリックします。

> **ルームIDの共有方法**  
> ロビー画面に表示される Room ID（例：`my-room-123`）を相手に共有してください。  
> URLをそのまま共有してもOKです（例：`http://localhost:3000/lobby?roomId=my-room-123`）。

## 2. カメラ・マイクの確認（ロビー）

ロビー画面でカメラとマイクの状態を確認してから入室できます。

![ロビー画面](screenshots/02_lobby.png)

| 操作 | 説明 |
|---|---|
| カメラプレビュー | 上部の映像エリアに自分のカメラ映像が表示されます |
| マイクボタン（🎤）| クリックでマイクのオン・オフを切り替えられます |
| カメラボタン（📷）| クリックでカメラのオン・オフを切り替えられます |
| Display Name | 通話中に表示される名前を入力します（必須） |
| Room ID | 参加するルームのIDが表示されます（変更不可） |
| Join Meeting | 入室します |

> カメラやマイクの使用許可を求めるダイアログが表示されたら **「許可」** を選択してください。

## 3. 通話室に入る

「Join Meeting」を押すと通話室に入ります。

### 1人で待機中

![通話室（待機中）](screenshots/03_room_waiting.png)

- 自分の映像が大きく表示されます
- 他の参加者が来るまで **「Waiting for others」** 表示になります

### 相手が参加したとき

![通話室（2人接続）](screenshots/04_room_connected.png)

相手が同じルームに入ると、自分と相手の映像が並んで表示されます。WebRTCによるP2P接続が自動的に確立され、映像・音声がリアルタイムで届きます。

## 4. コントロールパネルの操作

画面下部のコントロールパネルで各種操作ができます。

```
[🎤 ミュート] [📷 カメラ] [🖥 画面共有] [💬 チャット] [📵 退出]
```

| ボタン | 機能 |
|---|---|
| 🎤 マイク（青） / 🔇（赤） | マイクのミュート・ミュート解除 |
| 📷 カメラ（青） / 📷オフ（赤） | カメラのオン・オフ |
| 🖥 画面共有 | 画面・ウィンドウ・タブを相手に共有します |
| 💬 チャット | テキストチャットパネルを開閉します |
| 📵 退出（赤） | 通話を終了して退出します |

## 5. テキストチャット

通話中にテキストメッセージをやり取りできます。

### チャットを開く

コントロールパネルの **💬（チャット）** ボタンをクリックします。

![チャットパネルを開いた状態](screenshots/05_chat_open.png)

右側に「In-call messages」パネルがスライドして表示されます。

### メッセージを送る

![メッセージを送信した後（送信者側）](screenshots/06_chat_send.png)

1. 下部の入力欄にメッセージを入力します
2. 送信ボタン（紙飛行機アイコン）をクリックするか **Enter** キーを押します
3. 自分が送ったメッセージは右側に **「You」** ラベルで表示されます（濃い色のバブル）

### メッセージを受け取る

![メッセージを受信した後（受信者側）](screenshots/07_chat_receive.png)

相手が送ったメッセージは左側に **相手の名前** ラベルで表示されます（薄い色のバブル）。

### 双方向でのやり取り

![双方向チャット](screenshots/08_chat_exchange.png)

- 自分が送ったメッセージ → 右側・濃いバブル・「You」ラベル
- 相手が送ったメッセージ → 左側・薄いバブル・相手の名前ラベル
- 各メッセージには送信時刻が表示されます

> **ルーム分離**  
> チャットメッセージは同じルームIDの参加者のみに届きます。別のルームには一切届きません。

---

## 6. 通話を終了する

コントロールパネルの **📵（赤いボタン）** をクリックすると通話を終了します。

![退出後の画面（他のユーザーから見た場合）](screenshots/09_room_after_leave.png)

誰かが退出すると、退出した人のビデオタイルが消え、残ったユーザーの画面が全画面表示に戻ります。参加者が0人になるとルームは自動削除されます。

## よくある質問

**Q. カメラ・マイクが表示されない**  
A. ブラウザのカメラ・マイク許可設定を確認してください。URLバーの鍵アイコンから権限を確認できます。

**Q. 相手の映像が届かない**  
A. 現在のPoC版はSTUN/TURNサーバー未設定のため、同一マシン・同一LAN内のみ対応しています。詳細は [pitfalls.md](pitfalls.md) を参照してください。

**Q. ルームIDはどう決まるの？**  
A. 「New Meeting」で作成した場合はランダムなIDが生成されます。任意の文字列をルームIDとして使うこともできます（英数字・ハイフン推奨）。
